# LOOPLINE

A mobile-first co-op time heist for 2–8 players. Share private timeline clues, coordinate one action per player, and use the crew’s past moves as ghosts in the next loop.

## Accounts and reconnecting

Players must create an account with a username and password before creating or joining a room. No email or third-party sign-in is used. Passwords are stored as scrypt hashes, and session tokens are stored as hashes. On Vercel, account records are persisted in the connected Upstash Redis database. Sign in again after changing devices to reclaim your seat. Rooms stay rejoinable for 30 minutes after their last activity.

## Play locally

Requires Node.js 20 or newer. From this folder run `npm start`, then open http://localhost:3001 on each device on the same network (use the host computer’s LAN address for phones). Local accounts and rooms stay in memory and disappear when the server stops.

## Deploy to Vercel

1. Import this folder as the project root in Vercel. Choose **Other** as the framework preset; leave the build command blank and use this folder as the output directory.
2. Connect an Upstash Redis database through Vercel Storage/Marketplace. The API accepts the standard Upstash REST variable names and the prefixed names generated by Vercel's integration. Keep credentials in Vercel environment variables; never commit secrets.
3. Redeploy after connecting storage. Vercel routes each `/api` endpoint through a serverless function, and the shared handler serializes room updates through Redis.

The explicit API files include `/api/room/[code]` so room polling and host start actions are routed to the serverless handler. Vercel functions do not share durable in-memory state between instances, so Redis is required for accounts and online multiplayer.

## Controls

Create a room and share its four-character code or invite link. Everyone completes a short, skippable briefing; the host starts the run. Read your private memory aloud, agree on actions, and lock one move in one time slice before the countdown ends.
